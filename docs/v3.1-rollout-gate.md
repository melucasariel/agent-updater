The existing `-Install` path does not have a real automatic rollback or anti-downgrade check. **Do not fill both settings in the existing v3.0 configuration.**

## Candidate status

`candidates/GuardianUpdater-v3.1-CheckOnly.ps1` implements a real read-only updater check using:
- Strict Github release location restriction, no redirects.
- 15-second HTTPS timeout and 8 KB manifest size limit.
- Strict semver parsing and rejection of target <= installed version.
- Signing payload compatible with v3.0 (`version + LF + bundle_url + LF + lowercase SHA256`).
- RSA SHA256 public key validation (3072 bits minimum).
- Explicit rejection of the `-Install` argument.

It intentionally fails closed until `installed_version.txt` is set by a trusted local installer. No automatic installation is implemented or claimed.

## Next: supervised install with rollback

To qualify for unattended installs, implement and test a separate supervisor that:
1. Validates the signed update, ZIP SHA256 and archive entries **before** stopping the old monitor.
2. Stages the new Agent at a temporary path, syntax-checks it, and captures current Agent hash/backup.
3. Coordinates shutdown with a mutex/lock and waits for the old process to exit; no fixed sleep-only handoff.
4. Replaces the file atomically where supported and starts new Agent.
5. Requires a unique challenge-response from the new Agent (running PID, exact file hash, version) before commit.
6. Automatically restores backup and starts previous version on timeout/startup failure.
7. Commits `installed_version.txt` only after a healthy handshake; blocks downgrade and same-version replay.
8. Logs only redacted diagnostic status, preserves local DPAPI keys, and never modifies TaxiRadar/DB.
9. Tests successful switch, failed startup, delayed startup, corrupted ZIP, tampered manifest, expired process, power-loss and cancellation in a disposable sandbox.
10. Enables remote installation only after explicit approval and a verified trusted key bootstrap.

Do not run installer tests against the current active agent or Docker/PostgreSQL.
